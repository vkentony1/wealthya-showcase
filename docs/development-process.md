# Development process

1. **Problem:** identify the owner's decision task and where information is fragmented.
2. **Specification:** define the workflow, required behavior, data boundaries, and review criteria.
3. **AI-assisted implementation:** use AI tools to accelerate code and interface work against those requirements.
4. **Review:** inspect the outputs for product fit, correctness, privacy, and unsupported assumptions.
5. **Tests:** run relevant checks and examine behavior before treating a change as credible.
6. **Iteration:** revise requirements and implementation when review exposes gaps.

AI is an execution accelerator. Human judgment remains responsible for the problem definition, product priorities, acceptance criteria, and validation. A generated output is a candidate until reviewed.
